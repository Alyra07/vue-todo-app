# Vue Todo App

Solo Assignment 1 for the university course **NextGen Web Frontends**. The project is built with Vue 3, TypeScript and Vite.

## Setup

### Requirements

- Node.js
- npm

### Installation

Clone the repository:

```bash
git clone https://github.com/Alyra07/vue-todo-app.git
```

Navigate into the project directory:

```bash
cd vue-todo-app
```

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
